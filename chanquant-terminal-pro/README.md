# ChanQuant Terminal Pro · 个股预警助手

Windows 桌面入口启动本机预警程序，推荐使用**通达信行情直连**获取五分钟 K 线，合成已收盘三十分钟结构，监控截图中的 **43 只个股**。支持二买辅助、三买辅助、同日 23 买同步及优化二买确认，提供个股详情、桌面通知、声音和 CSV 日志。另保留通达信本地 `.lc5` 文件与东方财富来源。

## GitHub 下载

[下载 Windows 预警运行包](downloads/ChanQuant-Alerts.zip?raw=true)（需 Python）。如进入文件预览页，点击 **Download raw file**。下载后完整解压，再按下方步骤启动。

运行包包含预警功能和43只个股研究卡；测试、界面截图与离线66标的看板保留在仓库源码目录中。

## Windows 使用

安装 **64 位 Python 3.12**，完整解压本项目，再双击 `创建桌面快捷方式.cmd`。以后双击桌面的 `ChanQuant-Alerts` 即可；也可直接运行 `启动个股预警.cmd`。首次启动联网安装分析依赖；升级本版时还会安装 `pytdx==1.72`，随后自动打开本机页面。

在“行情数据来源”选择**通达信行情直连（推荐）**，主站地址留空时使用内置候选节点，也可填写你已确认可用的通达信行情主站地址与端口（通常为 `7709`）。先点击“检查行情连接”，核对实际连接节点、已收盘时点和历史数量，再保存设置、开始监控。

直连通过标准通达信行情 TCP 协议取数，不要求 `vipdoc` 或 `.lc5` 文件，不读取已安装客户端的内存或 DDE，也不使用东方财富 HTTP 接口。不需要账号、API 密钥或券商密码；**本机仍须能连接行情主站端口**，不能保证内置节点始终可用。新建配置默认直连，已有配置保留原来源，升级后请主动切换。

使用本地数据时，选择通达信本地文件模式并填写 `vipdoc` 目录，文件需自行持续更新。来源失败时停止该股本轮预警，不自动切换到其他提供方。

点击“启用桌面通知”和“测试通知通道”核对提醒能力。**首次扫描静默建立基线；来源失败、旧行情、缺口或历史不足时不发信号，也不使用模拟行情替代。** 冷启动要逐股取得并回放历史，43 股可能需要几分钟，请观察各股扫描状态。

升级时先在旧页面点击“退出程序”，完整解压新包覆盖原程序目录，保留已有 `.venv` 和 `app_data`，继续用原快捷方式启动。若解压到新目录，运行新目录里的 `启动个股预警.cmd`，并更新快捷方式位置。详细步骤见使用说明。

完整步骤、信号定义及常见问题见 [DESKTOP_ALERTS.md](DESKTOP_ALERTS.md)。界面由本机 Python 服务和浏览器提供；这是带双击启动脚本的源码包，需要 Python，并非独立 EXE。普通用户不需要 Node、Playwright 或测试工具。

## 开发验证

```bash
python -m pip install -r requirements-alerts.txt
python desktop_alerts.py --self-check
python desktop_alerts.py --no-browser
python -m pytest tests -q
```

测试另需安装 `pytest`。浏览器验收脚本为 `tests/browser_desktop.cjs`，在 Linux/云开发环境使用 Node Playwright 和 Chromium，可通过 `CQ_TEST_PYTHON` 指定安装了依赖的 Python。测试仅使用本机回环地址；通知通道在页面中记录验证，不能据此声称已测试 Windows 原生弹窗。

协议、联网模块的自动化检查与实际公网验证应分开看，当前进度见 [验证记录](desktop-preview/VALIDATION.md)。云环境尚未允许通达信公网 TCP 连接，不能据此声称节点实测成功；用户 Windows 电脑上的连接、数据时点与历史数量需通过“检查行情连接”核对。

原四阶段终端蓝图中的 ZLO 原公式、完整递归分类及 MiniQMT 自动执行仍属规划。当前版本尚未经过 Windows 真机的安装、通达信更新、联网获取和系统通知全流程验证。
