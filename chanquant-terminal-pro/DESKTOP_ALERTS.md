# 个股预警助手：Windows 使用说明

这是使用真实五分钟行情计算结构信号的桌面预警工具，推荐**通达信行情直连**，另保留通达信本地分钟文件和东方财富来源。默认监控截图中的 **43 只个股**，提供 **30 分钟二买辅助、三买辅助、同日 23 买同步、优化二买确认** 四种提醒。程序不连接券商、不报单，也不承诺收益。

## 1. 首次启动

1. 安装 **64 位 Python 3.12**，安装时勾选 **Add Python to PATH**。
2. 将项目**完整解压**到长期保留的目录，例如 `D:\ChanQuant`。不要在压缩包内运行；创建快捷方式后也不要随意移动项目目录。
3. 双击 `创建桌面快捷方式.cmd`，以后使用桌面的 `ChanQuant-Alerts` 快捷方式启动；也可直接双击 `启动个股预警.cmd`。
4. 首次启动需要联网安装 `czsc==1.0.2`、`pytdx==1.72` 及分析依赖；旧版升级也需补装通达信协议依赖。下载和安装可能需要几分钟，请保留启动窗口，等待浏览器自动打开。

界面由本机程序提供，默认地址为 `http://127.0.0.1:17343`。日常运行请保留启动窗口与浏览器页面。不要通过双击 `alerts/web.html` 打开界面。

**从旧版本升级：**先在旧页面点击“退出程序”，确认旧启动窗口结束，再将新运行包完整解压覆盖原程序目录，保留已有的 `.venv` 和 `app_data`，继续使用原快捷方式即可。不要只关闭浏览器标签页，旧后台仍可能占用原端口。若选择解压到新目录，直接运行新目录的 `启动个股预警.cmd`；旧快捷方式需要更新到新目录。

## 2. 选择真实行情来源

### 通达信行情直连（推荐）

1. 在“行情数据来源”选择**通达信行情直连（推荐）**。新建配置默认使用此来源；已有配置保留原来源，升级后请主动切换。
2. 主站地址留空时尝试内置候选节点。已有可用主站时，填写该 IP 或域名和端口，通常为 `7709`；可在你正在使用的通达信“通信设置／行情主站”中核对。自定义主站只连接指定地址，不暗中换为其他节点。
3. 点击“检查行情连接”，核对**实际主站 IP／域名与端口、末根5M时间、已收盘30M时间和完整历史数量**。确认来源及时点满足要求后，保存设置并开始监控。连接检查不创建买点提醒。

该模式使用 `pytdx` 的标准通达信行情 **TCP 协议**，取得5分钟 K 线，不依赖 `.lc5` 文件，不写入通达信目录，不读取已安装客户端的内存或 DDE，不使用东方财富 HTTP 接口，也不要求券商账号或密码。它仍需要本机联网并能连接相应行情端口；内置节点可能失效，不能保证任何主站始终可用。

五分钟请求使用协议类别 `0`，上海市场为 `1`、深圳市场为 `0`；每页最多800条，最多4页，目标3200条。价格为原始、不复权口径，成交量保留协议返回的股数，成交额使用源值。**3200是目标上限，不是已取得条数**；实际不足、空响应或错误会如实显示，不补造历史。

连接失败、超时、返回异常、历史不足、缺口或行情过旧时，页面显示原因并停止该股本轮预警。不会自动回退东方财富、模拟数据或旧快照。目录输入框在直连模式下不参与取数。

### 保留的东方财富来源

“联网5分钟行情（东方财富）”仍可手动选择。该模式使用公开 HTTP 接口，不要求本地目录或 API 密钥，可能受到接口访问、延迟或返回历史数量限制。它与通达信直连分别检查连接，不是直连失败后的自动回退来源。

### 继续使用通达信本地文件

先在通达信下载所选个股的完整 **5 分钟历史数据**，再在助手中填写实际的 `vipdoc` 目录。例如：

```text
D:\tdx\vipdoc\
├─ sh\fzline\sh600660.lc5
└─ sz\fzline\sz000858.lc5
```

上海个股通常使用 `sh\fzline\sh600xxx.lc5`，深圳个股使用 `sz\fzline\sz000xxx.lc5` 或 `sz300xxx.lc5`。可点击“检测目录”，未发现时手动填写目录。助手只读这些文件，不修改通达信行情。

通达信本地文件**不一定随看盘自动更新**。需要你在通达信持续下载或更新分钟数据。请核对界面的“最新已收盘 30M”和个股源时间；时间没有推进，就不能视为实时监控。

### 各来源共同的计算要求

程序按交易时段将 **6 根完整、已收盘的 5 分钟 K 线**聚合为 1 根 30 分钟 K 线，不补造缺失数据，不分析进行中的 K 线。前 **200 根完整 30 分钟 K 线用于预热**，从第201根起检查信号，即至少需要1206根可组成完整时段的5分钟线。建议本地下载覆盖更多交易日的历史。联网提供的历史数量不足时同样不能触发信号，不会自动降低预热要求。

冷启动会逐股取得并回放历史，43 股可能需要几分钟，各股状态会陆续更新。本地文件没有变化且仍在同一 30 分钟时段时会复用结果；行情文件或收盘时点变化后重新计算。扫描间隔指两轮扫描之间的等待时间，不保证整轮扫描在该秒数内完成。

## 3. 开始监控与验证提醒

1. 设置行情来源、扫描间隔、股票及规则，点击“保存监控设置”。本地模式另需有效数据目录。默认全部 43 股、四种规则、每 60 秒扫描一次，最短 15 秒。
2. 点击“启用桌面通知”，在浏览器弹窗中手动允许。权限被拒绝时，页面内提醒及日志仍可用；可在浏览器的站点设置中修改权限。
3. 按需开启“预警响铃”，点击“测试通知通道”。测试消息会明确标注“测试”，用于核对页面、桌面通知、声音和日志，**不代表真实信号**。
4. 点击“开始监控”。点击个股或预警日志，核对提供方或源文件、实际主站地址及端口、获取及数据截止时间、结构快照和触发证据。事件中的信号价格是**已收盘 30M 收盘价**，不是实时盘口价；原始价格口径和输入摘要用于追溯本次计算输入。

**首次启动、重新启动或暂停后再启动，都先静默建立基线。更换行情来源、主站地址或端口、目录、股票或规则也会重建基线。** 已存在的历史行情不补发提醒；只对后来观察到的当日最新已完成 30M 信号告警。数据过旧、近期缺口、历史不足或读取失败时不发送实时信号预警。当前没有提醒，不等于程序故障。

电脑休眠、程序退出、关闭启动窗口或浏览器页面后，不保证桌面通知和声音。浏览器权限、Windows 通知设置及专注模式也会影响弹窗。恢复后补录的旧行情不当作实时新信号推送。

推荐使用近期版本 Edge 或 Chrome。支持 Web Locks 和本地存储的浏览器会在多个页面间合并同一事件的通知及响铃；各页面仍可分别查看日志。

## 4. 四种规则的含义

| 规则 | 本程序采用的定义 |
| --- | --- |
| 30M 二买辅助 | CZSC 的 `cxt_second_bs_V230320`，使用 30 分钟、SMA21 参数；辅助状态从不满足变为满足时产生新事件。 |
| 30M 三买辅助 | CZSC 的 `cxt_third_buy_V230228`，使用已收盘 30 分钟结构；辅助状态首次转为满足时产生新事件。 |
| 同日 23 买同步 | 同一交易日内先后出现二买和三买**新事件**，第二类事件出现时确认，当日最多一次；不要求同一根 K 线。 |
| 优化二买确认 | 二买新事件后的 1～3 根连续 30 分钟 K 线内，收盘突破原信号 K 线高点，且 MACD 柱值大于 0、收盘高于 SMA60、SMA60 高于 5 根前数值。跌破原低点、超过窗口或出现时段缺口时取消；不跨日延续。 |

这些是 **CZSC 辅助结构的工程定义**，尚未验证为缠论研习院或大师兄课程原规则的完整复现。笔中枢参考也不自动等同于课程中的递归走势中枢。优化确认会延后提示，并不意味着收益更高。

个股研究卡中的业务、驱动、成立和失效条件是条件化研究资料，**不是当前行情结论**。没有取得真实行情时，页面显示“—”或待处理状态，不编造价格、买点及预期收益。

## 5. 日志与退出

- 点击“导出预警日志”，保存 CSV；日志区分消息生成时间、信号 K 线时间及原始事件时间，统一按北京时间展示。
- 设置与预警历史保存在项目的 `app_data` 目录。需要重置时，先导出日志、点击“退出程序”，确认程序结束后再删除 `app_data`；这会清除设置和历史记录，下次启动重新建立基线。
- 界面中的“暂停监控”只暂停扫描；“退出程序”结束本机后台程序。

## 常见问题

**双击后一闪而过或安装失败？** 先检查 64 位 Python 3.12 和网络。使用 `启动个股预警.cmd` 重试，并保留窗口内的错误信息；不要只复制某一个脚本到桌面运行。

**提示文件未找到、历史不足或缺口？** 核对 `vipdoc` 路径、证券市场前缀及 `.lc5` 文件，重新下载该股票的完整 5 分钟数据。只有日线文件不能用于本工具。

**本地目录为空，但想直接取通达信行情？** 将行情来源切换为“通达信行情直连（推荐）”，先检查连接，再保存并开始监控，无需下载 `.lc5`。若没有这个选项，先退出旧程序，完整更新后重新启动。

**通达信直连失败？** 核对电脑网络、主站地址和端口。自动候选节点均失败时，可填写你已确认可用的通达信行情主站；能浏览网页不代表能连接行情端口。页面会停止该股本轮信号，不改用其他提供方，不把旧快照或“测试通知通道”当作新行情。

**通达信客户端能看行情，助手却连不上？** 两者可能连接不同的主站。核对助手显示或填写的地址、端口与已确认可用的主站是否一致；仅打开客户端不会把其行情传入助手，直连模式会独立连接服务器。

**东方财富联网失败或数据错误？** 这是该 HTTP 来源的连接或数据问题，可明确切换到通达信直连并重新检查。各来源都可能返回不足或异常数据，程序不会保证每次连接成功。

**数据可分析但没有预警？** 可能尚未出现新条件，或当前只是初次基线。检查源时间是否更新到当日最新已完成 30 分钟时点；旧文件不会反复报警。

**测试有日志，但没有弹窗或声音？** 检查浏览器通知权限、Windows 通知与专注模式；响铃需先点击开启或测试以解锁浏览器音频。保持页面打开，页面内日志仍可查阅。

**提示会话失效或页面无法连接？** 请重新通过桌面快捷方式启动，不要使用保存的旧页面。若端口被占用，先确认是否已有助手运行，再关闭你确认的旧实例；不要随意结束其他程序。

**能自动买卖或保证正收益吗？** 不能。当前版本仅做只读预警，信号需要人工核验；它没有实盘报单功能，也没有提供经验证的收益保证。

已有版本做过自动化检查，各版本的验证状态见 `desktop-preview/VALIDATION.md`（仓库源码内）。**云环境尚未允许通达信公网 TCP 取数，也尚未在 Windows 真机验证安装、行情主站连接和系统通知全流程**。不能把离线协议测试当作公网连接成功；首次使用请先检查你电脑上的行情连接，再核对真实来源、数据时间和日志。
