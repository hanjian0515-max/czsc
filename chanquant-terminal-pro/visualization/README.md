# 66标的离线可视化

打开 `dashboard.html`，无需联网或安装。按阵营、资产类型、代码/名称/主题搜索筛选，点击卡片查看关系及30M/5M待分析信息，收藏保存在当前浏览器本地。

数据来自用户截图：43只股票、11只ETF、4个交易所指数、8个通达信本地参考指数。54项可交易，12项仅供观察；“可交易”是资产类别属性，不表示当前可成交或建议下单。

五阵营和主题是便于观察的业务暂分，不是研习院或大师兄已核验原文，也不代表主升、强弱、低风险或买卖评级。颜色表示阵营，不代表涨跌。ETF主题可能重叠，不是66个独立风险方向。

未取得最新行情：当前无价格、涨跌幅、笔、中枢或买点。截图日期未知，未把其中上证指数数值当成当前行情。`880xxx.TDX`保留本地命名空间，不能作为北交所股票或自动委托代码。

原始整理表在 `../research/universe_66_source.csv`；`symbol`列保留市场后缀，避免Excel省掉前导零或混淆上证指数与平安银行。510300截图名称被截断，保留短名“沪深300ETF”，没有伪补截图原文。

修改CSV后可执行 `python visualization/build_dashboard.py` 重建看板。该构建命令拒绝覆盖与新数据不一致的已有项目股票池配置，需要先人工核对差异。HTML内嵌全部样式、脚本和数据，无外部CDN。
