## v1.1：东方财富联网行情与溯源增强

新增可选东方财富公开五分钟行情及输入来源记录；本地模式保留。联网不依赖本地 `.lc5`，来源错误、过旧、缺口或历史不足时不发信号，不使用模拟行情回退。

v1.1 的 Python 回归 **406项通过**，包含112项联网响应机制测试、107项监控测试、72项真实回环HTTP测试，以及LC5、来源、CZSC、升级与命令行检查。联网输入均为明确标记的离线夹具，不代表取得真实公网行情。

v1.1 的 Chromium **27项检查通过**，新增模式切换、连接检查、失败不伪造信号和配置持久化；通知调用在页面记录、音频用真实AudioContext。无外部浏览器请求，无JavaScript错误。在线模式截图为空数据配置界面。

**真实公网取数尚未验证**：当前云环境生效白名单未包含 `push2his.eastmoney.com`，该域名只保存在环境配置草稿中。本版没有通过其他地址绕过策略，也没有把离线夹具当成真实行情。用户本机应先点击“检查行情连接”，确认接口可用、时点新鲜且完整30M至少201根；公共接口可能限制返回历史条数。

Windows 安装、联网取数和系统通知全流程仍待真机核对。事件的 30M 收盘价不等于实时盘口价，来源字段不构成当前买点或收益结论。

## v1.2：通达信行情直连

新增 `pytdx==1.72` 标准通达信行情 TCP 来源，可自动尝试内置节点，也可指定主站地址和端口。五分钟类别为0，沪深市场分别为1/0，每页最多800条、最多4页、目标3200条；实际返回条数和已完成30M数量以检查结果为准。新建配置默认直连，已有设置保留原来源。

该模式不读取 `.lc5` 或已安装客户端内存，不使用东方财富 HTTP 接口。来源证明增加实际主站地址、端口、节点名称与历史目标；连接失败不回退其他源、模拟数据或旧快照。原有完整时段聚合、201根完整30M要求、时效检查和首轮静默继续适用。

本版 Python 全量回归 **606项通过**，覆盖实际pytdx API签名、5M类别/沪深市场映射、分页顺序与重复阻断、原始量额、主站切换与自定义端口、失败短路、来源迁移、监控时效与HTTP/命令行接口。通达信响应测试均使用明确标记的离线假客户端，未建立公网行情连接。

Chromium **32项检查通过**，新增通达信主站配置/参数传递、非法端口提示、连接失败不回退其他源、配置持久化，保留通知去重、历史静默和移动布局检查。浏览器无JavaScript错误或外部请求；主站地址测试采用文档专用地址192.0.2.1，不代表有效行情节点。

**通达信公网取数尚未验证**：当前云环境未允许对应公网 TCP 连接，未尝试绕过策略，未取得真实主站响应。离线假客户端、协议格式测试或真实回环 HTTP 测试均不等于公网行情连接成功。Windows 端必须先检查实际主站、末根5M和30M时点及历史数量，再开始监控。

详细浏览器结果见 `browser-validation.json`。运行方法见根目录 `README.md` 和 `DESKTOP_ALERTS.md`。
